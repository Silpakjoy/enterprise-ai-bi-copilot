# System Users

## 1. Business Executive

### Purpose

The Business Executive uses the system to understand overall company performance.

### Can:

- View KPI dashboard
- View sales performance
- View profit performance
- Ask business questions
- View AI-generated summaries
- View charts
- View forecasts
- Generate reports

---

## 2. Business Analyst

### Purpose

The Business Analyst performs detailed business analysis.

### Can:

- Ask natural language questions
- Generate SQL queries
- Analyze sales
- Analyze customers
- Analyze products
- Analyze regions
- Create charts
- Investigate trends
- Generate reports

---

## 3. Finance Manager

### Purpose

The Finance Manager analyzes financial performance.

### Can:

- Analyze revenue
- Analyze profit
- Analyze expenses
- Analyze financial reports
- Compare financial periods
- Generate financial summaries
- Generate reports

---

## 4. Administrator

### Purpose

The Administrator manages the application and system.

### Can:

- Manage users
- Manage permissions
- Manage database access
- Monitor system activity
- View system logs
- Manage application settings
