# Contributing

Thank you for your interest in contributing to the Enterprise AI Business Intelligence Copilot.

## Development Setup

1. Clone the repository.
2. Create a Python virtual environment.
3. Activate the virtual environment.
4. Install the required dependencies.
5. Configure the environment variables.
6. Run the development application.

## Contribution Process

1. Create a new branch for your changes.
2. Make your changes.
3. Test your changes.
4. Commit your changes with a clear commit message.
5. Push your branch to GitHub.
6. Open a pull request.

## Code Guidelines

- Write clear and readable Python code.
- Use meaningful variable and function names.
- Keep functions focused on a single responsibility.
- Add comments where they improve understanding.
- Avoid committing passwords, API keys, or other secrets.

## Documentation

Update the relevant documentation when making significant changes to the system architecture, database, APIs, analytics, AI workflow, or project features.

## Security

Never commit:

- `.env` files
- API keys
- Database passwords
- Access tokens
- Other confidential information
