# Enterprise AI Business Intelligence Copilot

An AI-powered Business Intelligence platform that allows business users to ask questions about company data using natural language.

## Main Features

- Natural Language to SQL
- AI Business Intelligence Chat
- PostgreSQL Database
- KPI Dashboard
- Business Analytics
- AI-generated Business Summaries
- Sales Forecasting
- Financial Report Analysis
- PDF Report Generation
- Voice Input
- Chart Explanation
- Power BI Integration

## Technology Stack

- Python
- SQL
- PostgreSQL
- Streamlit
- FastAPI
- Pandas
- NumPy
- Scikit-learn
- Power BI
- Generative AI
